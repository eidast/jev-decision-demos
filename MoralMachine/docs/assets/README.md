# README preview provenance

`decision-example.png` is a screenshot of this repository's local web UI, captured at a 1280-pixel browser viewport on September 22, 2026 after the neutral road diagram change. It shows case 1 before the tester chose either option. `result-example.png` is an earlier 1200-pixel capture of the same demo's completed 13-case run, with A deliberately chosen in every case and a live OpenRouter Jev response. The reported 4/13 agreement and 22% mean selected probability describe that one test run only. `exercise-preview.gif` is an older animation of the previous decision-card layout and the result capture; the README now uses the current static decision image.

The screenshot of the results hides the saved run ID and timestamp to keep the preview focused. No probabilities, choices, or labels were changed. No API key, private report JSON, or other participant's choices are stored in these files. The images illustrate the product flow and are not research results or official Moral Machine scenarios.

The screenshots contain official Moral Machine character portraits as part of the UI. Their provenance and project-level CC BY 4.0 attribution are recorded in [THIRD_PARTY_ASSETS.md](../../THIRD_PARTY_ASSETS.md). The surrounding interface and screenshot composition are original to this repository.
